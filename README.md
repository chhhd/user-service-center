# user-service-center

참가자가 가상 청년 프로필을 선택하고 개인정보 제공 범위를 결정한 뒤, 금융·청년정책 추천과 개인정보 추론 결과를 확인하며 동의를 다시 수정해보는 체험형 웹 애플리케이션입니다.

모든 값은 체험용 가상 데이터이며 브라우저 메모리에서만 관리합니다. 실제 개인정보 입력, 서버 전송, `localStorage`, `sessionStorage`는 사용하지 않습니다.

## 전체 화면 흐름

1. 금융 코치 시작 및 가상 프로필 선택 — **구현 완료**
2. 개인정보 제공 범위 선택 — **구현 완료**
3. 금융생활 정보 입력 — **구현 완료**
4. 금융·청년정책 추천 결과 — **구현 완료**
5. AI 개인정보 추론 결과 공개
6. 데이터 활용 리포트 및 수정 전 스냅샷 생성
7. 동의 내역 다시 선택 및 전체 결과 재계산
8. 최종 결과표
9. 부스 마무리 및 상태 초기화

## 핵심 구현 원칙

- STEP 2부터 STEP 7까지 모든 개인정보 항목은 동일한 `field_id`를 사용합니다.
- 개인정보 정의는 [`src/shared/dataFieldMeta.js`](src/shared/dataFieldMeta.js) 한 파일에서 관리합니다.
- 동의하지 않은 항목은 가상 프로필에 값이 존재해도 추천·추론 입력으로 사용하지 않습니다.

## 폴더 구조

```
src/
  data/            # 가상 프로필, 금융 목표 정의
  shared/          # 공통 상태(journeyStore), 개인정보 메타데이터, 동의 규칙
  step1/           # 서비스 소개, 프로필/목표 선택
  step2/           # 개인정보 제공 범위 선택 (동의 방식, 제3자 제공, 보관 기간)
  step3/           # 금융생활 정보 입력
  step4/           # 금융·청년정책 추천 결과 
```

## 개발 실행

```bash
npm install
npm run dev
```
